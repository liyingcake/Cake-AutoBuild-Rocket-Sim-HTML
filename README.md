# Cake AutoBuild Rocket SIM

基于代码图形与HTML运行的模拟器类游戏。
离线运行的中文火箭概念设计、试车与一维直飞教学模拟器，可按任务指标、组件材料和发动机循环动态生成尺寸、性能与制造成本。
目前为初代，版本代号 v1.2 MoarBooster
增加了助推器和分级概念

## 运行

直接双击 `index.html`。项目不使用网络请求、前端框架或构建步骤；CSS、数据和脚本均在本目录中。

## 功能

- 推进剂总量、目标 Δv、目标推力＋燃时三种反算方式；任务步骤同时提供储箱直径模式、锁定直径和自动长径比入口，并与储箱步骤中的原入口双向同步。
- 9 组推进剂预设、自定义推进剂、26 个代表材料条目、6 种发动机循环和 3 种冷却方式。
- 设计向导、储箱/发动机专家参数、环境、发射时序、声音和能量统计选项均提供文字提示；鼠标停留或点击参数文字会展开功能目的、计算原理、当前值、单位、允许范围，并为当前推进剂、材料、工艺、循环、电池和天体预设显示对应工程说明。点击输入框、选择框等控件本身不会弹出提示，`Esc` 或点击其他区域可关闭。
- 所有带有效 `step` 的数字输入框右侧提供细长的绿色步进量级调节器：上箭头依次切换 `1× → 10× → 100× → 1k×…`，下箭头依次切换到 `0.1×`、`0.01×`；倍率只改变原生上下键/键盘方向键的单次步进，不修改当前数值。重复出现的同一参数会同步倍率，选择会保存在本机。像“经验结构系数＋恢复默认”这类同时带操作按钮的参数会独占一整行，避免输入框、倍率器和按钮互相挤压。
- 理想 Δv、总成本、起飞质量和总推力/推重比四张关键结果卡采用顶部冻结布局；页面滚动时始终停留在顶栏下方，并通过实时测量顶栏高度避免在不同窗口宽度和顶栏换行时相互遮挡。
- 储箱支持单层壳体、旧版固定 5:95 双层、动态载荷共享双层、COPV、整体加筋、夹芯壳体和压力稳定气球结构。动态分层模式按温度修正后的 `E·t` 刚度迭代载荷分配，并计算热膨胀失配、预应力、界面剪切、内衬卸压皱曲、膜应力、轴向屈曲折减和压力循环利用率；旧版 5:95 仅保留为历史方案兼容选项。
- 储箱材料下拉框会按当前推进剂的燃料/氧化剂温度实时筛查材料工作温区；不覆盖所需温度的条目会显示红色 `⚠ … · 温区不符`，若当前已选材料不合格，收起状态的选择框也会变红。单层主壳按两种工质共同检查，内衬按接触侧检查，共底按单层/双面板构型检查，外承力层则按界面热耦合后的结构温度检查；切换推进剂、共底形式、界面模式或自定义温度时立即刷新。
- 双组元推进剂可在独立双箱和共底储箱之间切换。重做后的共底不再用固定 `1.18×` 面积、统一壁厚和任意芯层面密度：以可调球冠拱高求曲率半径与真实曲面面积，可选择自承式单侧失压包络或依赖压差联锁的压力稳定式，并施加可调证明系数。单层压差膜同时检查正向膜应力、反向外压屈曲和穿壁热漏；双层真空结构让两张壳分别按各自箱压承压；粘接蜂窝夹芯按两侧材料与温度分配面板载荷，并检查夹芯整体稳定、芯层压溃、面板起皱、热失配粘接、环桥热漏和冷侧等效蒸发。被取消封头的壳体、加筋与绝热质量按原箱几何/厚度分项扣除；新增质量则拆成面板、芯层/热障、Y 环/密封/监测。BOM 只显示带正负号的物理净质量，毛质量仅作制造计价基准；成本另拆两侧面板、芯层、环件/密封及工装/NDE。缩短箭体的蒙皮、表面系统、布线和支撑潜在节省继续集中显示为“共底带来的重量削减的其他优势”，且不回写结构干重、起飞质量、Δv、飞行或成本。气球储箱另有最低维形压力、持续供气和地面张紧/运输工装模型。
- 储箱加工工艺加入旋压封头、摩擦搅拌焊、整体铣削网格、流动成形整体加筋、内衬＋纤维缠绕、夹芯粘接和蜂窝共底；工艺会影响最小厚度适用性、接头效率、性能折减、备料损耗与成本。
- 默认使用真实比例火箭侧视图，并可切换到固定 Q 版；编辑待机时默认采用图纸黑/太空黑背景，可用“待机模拟大气”开关预览所选天体的大气色。
- 九种天体环境的一维直飞、最大动压/过载限制和确定性地面试车；新增真实金星约 9.2 MPa 高温大气与概念性的 500 kPa 部分地球化金星，高于 101.325 kPa 的稠密大气会继续降低有效比冲、推力与排气速度。
- 首轮多构型更新加入可选的液体并联助推器（Add Moar Booster）：支持 1–8 枚相同助推器，推进剂量按芯级比例联动或固定单枚质量；推进剂、直径和发动机均可复制芯级或独立选择。核心模型分别计算每枚助推器储箱、发动机、箭体、推进剂与成本，叠加连接/分离结构、并联气动包络和多次分离可靠性；目标 Δv 反算可选择使用完整的“共同燃烧—助推器燃尽—延迟分离—芯级续航”分段质量事件。直飞积分独立消耗芯级和助推器推进剂，在分离瞬间抛掉真实干重/残余/连接质量，并切换到芯级迎风面积；Q 版和真实比例图均显示助推器、独立尾焰、剩余量与淡出分离。当前阶段只实现液体/单组元并联助推器；串联二/三级与固体推进剂留待下一轮。
- 尺寸反算可在目标起飞推重比与目标离架净加速度之间切换；净加速度模式按当地重力反算推力，便于跨天体比较。
- 挤压供给教学室压上限为 6 MPa；电泵热机械发动机采用 0.10× 成本修正，并提供一次锂电、二次锂离子、高功率锂聚合物、银锌、锂硫和自定义特殊电池。电池质量同时检查比能量与比功率约束，并计入储能余量、封装、电机、控制器、输出功率和成本。
- 多发动机集群默认按独立发动机建模：每台重复计算泵、控制器、阀门、点火器、万向节、安装件与验收试车，并叠加集群推力架、分流管路压降、振动结构修正、喷口俯视排布/箭体扩径检查及一台失效后的任务可靠性。也可选择共用动力包；“理想模式—单泵多燃烧室多喷口”保留旧模型的共享优势，但不会绕过喷口包络和扩径校核。
- 可播放的点火试车与直飞演示：尾焰随推力/高度变化、储箱余量实时下降，并显示相对箭体前进方向的速度、净加速度、重力加速度和阻力加速度箭头；同步标记当前动压 Q、节流阀状态、环境压力、喷口出口压力、当前推力、燃料/氧化剂流量和有效排气速度。
- 直飞演示下方提供持久遥测框，保留高度、速度、净加速度、动压 Q 与实际时间加速倍率；理想 Δv 卡片在顶点/状态说明下显示熄火时速度和关机高度。
- 当一维直飞运行至 3600 秒教学积分上限时，理想 Δv 卡片的上限说明下方及结果区都会显示 T+600 秒与 T+1800 秒的绝对高度和相对发射点上升距离。
- “能量统计”结果页以飞行时间为横轴、统一能量纵轴同步绘制飞行器剩余总能量、剩余化学能/内能、重力势能和飞船动能，可切换自动、TJ、GJ、MJ、kJ 单位；动能峰值以垂直虚线和四个同刻数据点标记，并显示该刻速度、高度、各项能量及比能量/机械能转换统计。统计范围可在“直到速度归零”和“燃尽后追加滑行”之间切换，后者默认追加实际燃时的 10% 且可在 0–200% 调整，图中以燃尽线、滑行着色区和截止线区分；即使轨迹已达到逃逸教学判据，也会继续积分到所选追加滑行终点。
- 方案名称可切换为自动生成，按计算后的箭体直径级别、推进剂组合和发动机循环实时组合，例如 `5米级-甲烷液氧-燃气循环火箭`；关闭后可继续手动命名。
- 结构/成本步骤把经验结构系数的概念级推荐基准设为 `0.055` 并提供一键恢复；装配系数、总体价格修正和各项参考单价收纳进默认关闭的“价格调试模式”。价格总体修正默认及复位值始终为 `1.00×`，价格复位会按当前推进剂与材料重新载入参考价。
- 起飞质量卡先显示推进剂、结构干重和载荷相对起飞质量的占比，再单独显示完全排除推进剂的干重分配：储箱、发动机/管路、箭体、增压/航电，以及可选计入的载荷。载荷默认不计入干重分配分母；干质比采用 `m湿/m干`，以大于 1 的无量纲质量比显示。其倒数另存为“干质量分数”，避免再把两者混为百分比。
- 顶栏在 Rocket SIM 标志与设计校验状态之间轮播 50 条火箭科学段子和航天先驱/宇航员名言；进入应用、每次开始试车或直飞演示时切换，之后每 3 分钟切换一次。常规模式用 1.5 秒淡出＋1.5 秒淡入组成 3 秒过渡，系统启用“减少动态效果”时会取消长动画。
- 默认启用 T-10（可选至 T-13）发射倒计时和中文语音报数；沉浸模式从倒计时到 T+5 固定 1× 播放。发动机按可调时间从零爬升，发射场模式在 T/W > 1 持续 1 秒后解锁摇臂，野地模式则在 T/W 首次超过 1 时离地，两者都会计入点火后、离地前的推进剂消耗。
- 可选“熄火后 1 秒自动暂停”，默认关闭并连续演示惯性滑行；启用时直飞画面精确停在熄火后 1 秒，声音和运行状态同步停止，手动继续后不会重复暂停。
- 环境模拟包含地球、火星、月球、水星、土卫六、木卫二和谷神星，计算会切换当地重力、半径、大气/真空与阻力；背景由天体地表色随高度渐变至宇宙黑。
- 每种推进剂具有独立的风格化尾焰配色、宽度和长度倾向，便于在模拟与试车中直观区分。
- 使用 Web Audio 即时合成独立的点火、低频轰鸣、喷流和涡轮声部；支持各声部音量、8–12 秒试听保护渐降及可选的环境压力/真空衰减，并将偏好保存在本机。
- 成本 BOM 会按所选工质分别计入燃料/单组元推进剂与氧化剂的装载质量、可编辑参考单价和小计；顶部总成本卡显示推进剂、储罐、箭体、泵/阀、燃烧室/喷管及其他系统的成本占比。另含公式检查器、方案保存、双方案比较及版本化 JSON 导入/导出。


## 重要边界

本项目使用公开参考资料和简化关联式进行教学级概念估算，不包含完整化学平衡、CFD、非线性屈曲有限元、层合板 ABD 矩阵、界面断裂力学、瞬态共底传热、裂纹扩展、燃烧稳定性、详细涡轮机械叶型、控制系统或安全认证模型。结果不得用于制造定型、载人任务、危险化学品操作或发射决策。
